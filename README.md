# QQQTrust 的博客

这是 `QQQTrust.github.io` 用户站点仓库，发布地址为：

https://QQQTrust.github.io/

## 如何写博客

1. 进入 `_posts` 目录。
2. 新建 Markdown 文件，文件名格式为 `YYYY-MM-DD-title.md`，例如 `2026-08-10-first-post.md`。
3. 文件开头写 Front Matter：

```md
---
layout: post
title: "我的新文章"
date: 2026-08-10 10:00:00 +0800
category: 技术
tags: [GitHub Pages, 博客]
---

这里写正文。
```

4. 点击 Commit changes。
5. 等 GitHub Pages 构建完成后，文章会出现在网站首页。
